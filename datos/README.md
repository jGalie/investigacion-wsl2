# Datos del experimento de archivos

Según el artículo, se utilizó un CSV sobre vuelos de enero de 2025 con **243.177.378 bytes** y **539.748 líneas** (incluido el encabezado), que permitió identificar **8.327 vuelos con origen JFK**.

El archivo original **no se incluye** por su tamaño y porque antes de publicarlo es necesario verificar su origen y condiciones de reutilización. Tampoco se incluye una reconstrucción del script de filtrado: debe incorporarse la versión realmente utilizada por el grupo para que las mediciones puedan reproducirse.

**Información pendiente de aportar:** enlace/autor de origen del dataset, licencia o condiciones de uso, nombre del archivo y script original de filtrado, si se conservan.

Las dos ejecuciones medidas se realizaron dentro de WSL2, variando la ubicación del archivo (`/home` y `/mnt/c`), no sobre sistemas operativos nativos diferentes.
